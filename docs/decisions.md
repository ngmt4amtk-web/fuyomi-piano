# ふよみ ピアノ版

バイオリン版とは別アプリ・別保存領域。4音を1音ずつ読む。和音・拍・両手同時は判定しない。

## レベル
1. 中央ド〜ソ C4–G4（60–67）
2. 1オクターブ C4–C5（60–72）
3. 少し高く C4–G5（60–79）
4. 低い音も G3–G5（55–79）
5. もっと高く G3–C6（55–84）
6. 3オクターブ G3–G6（55–91）

既定はハ長調・A4=440Hz。調の選択はC/G/D/A。音域内の調の音から出題する。
ト音記号だけを使い、低いソも加線で表示する。
画面の音名は数字を使わず、C4未満「低い」、C4〜B4「普通」、C5〜B5「高い」、C6以上「すごく高い」。中央ドは「普通のド」。
指番号や手の指定は出さない。ヒントは音名、その次に鍵盤の位置。
最終音G6を含む全音域を検出対象とし、オクターブ違いは通さない。
ピアノの減衰を考慮した短い保持時間。同じ持続音は二重合格にしない。別音への切り替わり、無声、新しい打鍵の立ち上がりで再開する。ペダルは使わない。
確認用のラは不要。マイク取得後そのまま問題へ進む。マイク不許可時は手動でも使える。
相棒3種類・透過画像・正誤反応・任意のクリアタイマーを継承。
6段階の相棒は1→1、2→2、3→3、4→4、5・6→5。最終2段階は王冠を共用。
タイマーは最初の問題から最後の音まで。準備・最終ファンファーレを除く。
