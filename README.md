# ふよみ ピアノ版

ピアノで4音ずつ譜読みを練習するWebアプリ。外部ライブラリ・ビルド工程なし。

1. 中央ド〜ソ（C4–G4）
2. 1オクターブ（C4–C5）
3. 少し高いソまで（C4–G5）
4. 下のソも加える（G3–G5）
5. もっと高いドまで（G3–C6）
6. ソからソ・3オクターブ（G3–G6）

ト音記号の譜面／音名と鍵盤ヒント／マイクの1音判定／手動モード／3種類の相棒／任意のクリアタイマー。
1音ずつ、ペダルを使わずに弾く。和音と両手同時演奏、リズムは判定しない。
マイク音声は端末内で処理し、保存・送信しない。設定の保存キーはfuyomi-piano。

実行: `python3 -m http.server 8766 --bind 127.0.0.1`
検証: `node tests/run.mjs`

譜面記号はBravura（SIL OFL 1.1）。LICENSES.md参照。
基礎はふよみバイオリン版から分離。バイオリン版のコードや保存設定は変更しない。
